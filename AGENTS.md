# Project agent instructions

## Design skill

For any task that builds, edits, styles, reviews, or writes copy for the website UI, first read and apply:

`.agents/skills/landing-page-design/SKILL.md`

This skill is sourced from:
https://github.com/elayadesign/ai-design-skills

Project-specific rules:
- The user's explicit instructions always take priority over the design skill.
- Preserve the current PortfolioV2 visual identity and information architecture unless the user explicitly asks for a redesign.
- Do not add sections, animations, conversion patterns, forms, or marketing elements merely because the skill recommends them when they do not fit an academic portfolio.
- Treat the skill as a design-quality checklist and implementation reference, not permission to overwrite established project decisions.
